# Portfólio — Enzo Leal

Portfólio pessoal desenvolvido com HTML, CSS e JavaScript.

## Como abrir

1. Extraia todos os arquivos da pasta.
2. Abra a pasta no Visual Studio Code.
3. Abra o arquivo `index.html` com o Live Preview ou diretamente no navegador.

## Páginas

- `index.html`: apresentação pessoal e playlist do Spotify.
- `sobreMim.html`: informações pessoais, formação, conhecimentos e intercâmbio.
- `projetos.html`: projetos desenvolvidos.
- `sentinela.html`: descrição completa do projeto SentinelaLog, funcionalidades, tecnologias e instruções de execução.

## Arquivos de estilo e recursos

- `design.css`: estilos da página inicial.
- `sobre.css`: estilos da página Sobre mim.
- `projetos.css`: estilos da página de projetos.
- `default.css` e `sentinela.css`: estilos da página SentinelaLog.
- `assets/enzo-leal.jpg`: foto de perfil.
- `assets/windows-media-player.jpg`: moldura visual inspirada no Windows Media Player clássico.
- `assets/fundo-principal.png`: imagem de fundo do site.

O projeto utiliza HTML, CSS e JavaScript simples, sem frameworks.
